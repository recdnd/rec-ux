ベンチ引き継ぎキー

Bench Handover Keys

人が使う作業台から、ワンクリックで agent に引き継ぐ。
鍵は 3 本：現状 ・ ルール ・ 変更。

3 本の鍵

鍵答えること中身の出どころ押すとき
📑現状このページに今なにがあるかページの状態オブジェクト（DOM ではない）agent にこの 1 件を理解させる
🤖📓ルールどう書くべきか仕様 md の要約 + 正本のパスagent が手を動かす前
📋→🤖変更今どこを触ったかサイトにある diff / 下書きagent に正本へ書き戻させる

なぜ 3 本か

  • 現状だけ渡すと、agent は自分の癖で書く。
  • ルールだけ渡すと、今どうなっているかが分からない。
  • 変更だけ渡すと、前後の文脈が見えない。

1 本でも欠けると、引き継いだ側が一度聞き返すことになる。

動き

押す → テキストを組む → クリップボードに書く → ボタン面が ✓ / ❌ を 0.5 秒 → 元に戻る
📑🤖📓📋→🤖

ルール

  • 出すのはファイルではなくテキスト。クリップボードがインターフェースで、対話欄に貼ればそのまま使える。
  • 現状は状態から組む。画面の文字は欄幅で切れているので、削り取ると文が欠ける。
  • ルールは仕様そのものではなく、貼ったらすぐ動ける要約。 1 行目に正本の場所。
  • 3 本とも読むだけ。状態は書き換えない。
  • いちばんよく押す鍵がいちばん右。新しい鍵は左へ足す。
  • 選択中の 1 件がないとき「現状」は ❌。空の殻はコピーしない。

やらないこと

  • 3 つを 1 つのボタンにまとめる（長くて要点がない）
  • クリップボードの代わりにファイルをダウンロードさせる
  • 鍵のついでにデータを直す
  • 「コピーしました」のトーストを出す（返事はボタン面の ✓ / ❌ だけ）
